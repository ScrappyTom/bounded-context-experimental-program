## Why E79 changed the design

The sealed Keystone actor read complete sources in exact catalog order:

```text
MANDATE → TRACK → SIGNAL → POWER → ROLLING → CREW → WEATHER → FUEL
→ CYBER pending
```

Eight source bodies crossed later actor decisions. The ninth was acquired but
could not be delivered. The candidate remained the empty seed. The run spent
101,778 prompt tokens and 231 completion tokens, about 441 prompt tokens per
completion token, without creating durable semantic or task-work state.

This was not evidence that eight sources were intrinsically insufficient. The
live actor selected complete 86-line single-source reads, while offline Stage 0
had demonstrated a legal but behaviorally unrealized partial-pair path. The
ten-source/ten-domain gate therefore mixed accessible geometry with realized
actor behavior. It is retired rather than lowered.

The transcript appendix also establishes a confound: the read order is
semantically coherent but exactly matches catalog order. It cannot be credited
as independent semantic prioritization.

## Event-triggered successor

The exact E79 state is now the immutable common prefix. Common infrastructure
performs the already earned positive-savings first-fit substitution of
`RESULT-001`, delivers pending `RESULT-009` CYBER, and continues ordinary
actor-selected construction and verification.

No treatment may appear until the trace contains:

1. a nontrivial candidate entering verification;
2. a current check bound to that candidate;
3. a rejected mutation with no candidate change;
4. a later exact source or reopen observation acquired with no intervening
   candidate change; and
5. no later actor decision.

The common state is cloned immediately before the next decision, whose prompt
delivers the pending observation in both arms.

`V0_CURRENT_ONLY` omits the unresolved rejection and recurrence from the
bounded projection. `V1_BOUNDED_CAUSAL_CONTINUITY` retains those exact facts
until candidate change. Both share custody, relief, source access, temporary
anchored construction support, exact incremental work, current check,
candidate/artifact/section-bound repair, evaluator, budgets, and closure rules.

The prospective integrated run freezes at most 18 common model calls, eight
actor calls per measured arm, 34 new model calls total, and 700,000 newly
serialized tokens. There is one attempt per call and zero retries. If the live
trigger is absent, the run closes as `causal_trigger_not_observed` without a
fork. Activation tax includes the original nine E79 calls and 102,009 tokens.
