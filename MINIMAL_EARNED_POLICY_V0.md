# Minimal earned policy v0 — index and disposition

Date: 2026-08-22
Status: candidate for a fresh-task whole-method scout; not a promoted architecture

The prior combined policy document has been split so the causal treatment is
not confused with common evaluation governance:

- `MINIMAL_RUNTIME_POLICY_V0.md` defines what changes model-facing execution;
- `MANDATORY_EXPERIMENTAL_GOVERNANCE.md` defines common custody, parity,
  evaluation, readiness, replication, and Stage 0 requirements.

## Earned incumbent

```text
exact external custody and access
+ ordinary chronology while healthy
+ host-owned capacity accounting
+ same ordinary response reserve in both arms
+ treatment-paid exact transition reserve
+ deterministic first-fit relief under a frozen scan order,
  stopping immediately at first feasibility
+ exact reopen on actor demand
+ task-authored bounded phase reentry
+ hard call/token/time budgets
```

This is a **mechanical safety and lifecycle substrate**. It has not demonstrated
reliable end-to-end task performance.

Semantic notes, digests, progress state, model-managed residency, automatic
phase discovery, and learned routing remain excluded from the default policy.

## Next experiment

The next experiment is named `qwen38-fresh-task-whole-method-scout-v0` and uses:

- one fresh large-document research/writing task;
- one fresh multi-file code task;
- control and treatment under common evidence/evaluator governance; and
- two frozen seeds per condition when the offline design remains eligible.

The scout is a compound-policy test. A win supports the full policy in that
configuration, not the necessity of every component. A loss routes the next
study from the first genuinely new exact failure boundary.

No GPU use is authorized by these documents. Offline task/evaluator/phase and
reserve qualification must complete first.
